\subsection{Positioning Systems}
\label{sec:positioning}

\emph{Wireless positioning systems} are used by mobile operating systems to
compute their own locations. These systems use landmarks---either \wifi \acp{AP}
or cellular base stations---with known locations to provide devices attempting
to self-geolocate with reference points to do so. Devices using \acp{WPS} use
\acp{BSSID}---MAC addresses of \wifi \acp{AP}---that are broadcast in 802.11
\wifi management frames to identify nearby landmarks, while those using
\acp{CPS} use cellular base station identifiers
